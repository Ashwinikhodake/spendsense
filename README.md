# SpendSense

AI-powered expense tracker built with Flutter and ASP.NET Core.

## Tech stack
- **Mobile:** Flutter, Riverpod, go_router, Dio
- **Backend:** ASP.NET Core (.NET 8), EF Core, JWT auth, Clean Architecture
- **AI:** LLM-based expense parsing (text, voice, receipt)

## Status
In development. Backend setup in progress.

## Project structure
- `backend/` – ASP.NET Core Web API
- `mobile/` – Flutter app
- `docs/` – architecture and design notes
